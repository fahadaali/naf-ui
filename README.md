# naf-ui

نظام التصميم الموحّد لشركة ناف القانونية.
سجلّ `shadcn` يحوي الثيم والخط والشعار والمكوّنات المعتمدة للمنصات الخمس.

عنوان السجلّ: `fahadaali/naf-ui`

---

## الاستخدام

أضف السجلّ في `components.json` عند المنصة:

```json
{
  "registries": {
    "@naf": "https://raw.githubusercontent.com/fahadaali/naf-ui/main/public/r/{name}.json"
  }
}
```

ثم اسحب ما تحتاجه:

```
npx shadcn@latest add @naf/naf-theme
npx shadcn@latest add @naf/button
```

التثبيت على إصدار محدد: `@naf/button#v1.1.0`

---

## عناصر السجلّ

سبعة عشر عنصراً.

### الهوية

| العنصر | النوع | المحتوى |
|---|---|---|
| `naf-theme` | ثيم | رموز الألوان والمقاسات والظلال للوضعين. لا تعدّل قيمه. |
| `naf-font` | ملف | IBM Plex Sans Arabic بأوزان 400 و500 و600 و700، مستضاف ذاتياً. |
| `naf-currency` | مكوّن | رمز الريال `U+20C1` بوزنيه، ومكوّن المبلغ وبديله النصي «ر.س». |
| `naf-logo` | مكوّن | خمس نسخ من الشعار، ومكوّن يختار النسخة حسب الوضع، وأيقونة المتصفح. |

### المكوّنات

| العنصر | النوع | المحتوى |
|---|---|---|
| `button` | مكوّن | الزر — ثلاثة ارتفاعات. |
| `input` | مكوّن | الحقل. |
| `card` | مكوّن | البطاقة. |
| `dialog` | مكوّن | النافذة المنبثقة. |
| `alert` | مكوّن | التنبيه — خمسة أنواع بأيقونة ونص. |
| `table` | مكوّن | الجدول — أرقام متساوية العرض. |
| `utils` | مكتبة | دالة دمج الأصناف. |
| `naf-format` | مكتبة | المبالغ والأرقام والتواريخ الميلادية والهجرية والوقت والجوال. |

### الحوكمة

| العنصر | النوع | المحتوى |
|---|---|---|
| `naf-terms` | ملف | مصطلحات الواجهة — المرجع الوحيد لكل نص يظهر للمستخدم. |
| `naf-icons` | ملف | خريطة أيقونات Lucide وقواعد القلب في الاتجاه من اليمين لليسار. |
| `naf-rules` | ملف | `CLAUDE.md` والمصطلحات والأيقونات إلى جذر المشروع. يجلب `naf-skills`. |
| `naf-skills` | ملف | مهارات كلود كود الثلاث: الربط، وفحص الانحراف، والتحقق من الأيقونات. |
| `naf-governance` | ملف | أتمتة الإصدارات وقالب وصف الالتزام. يجلب `naf-rules`. |

**لتهيئة منصة جديدة، أمر واحد:**

```
npx shadcn@latest add @naf/naf-governance
```

يجلب الحوكمة كاملة — القواعد والمصطلحات والأيقونات والمهارات وسير الإصدار.

## الإصدارات

آلية. تُشتقّ من أوصاف الالتزامات عند الدمج في `main`:

| وصف الالتزام | النتيجة |
|---|---|
| `fix:` | إصلاحي |
| `feat:` | ثانوي |
| `feat!:` أو `BREAKING CHANGE:` في الشرح | رئيسي |
| `docs:` `refactor:` `chore:` `ci:` وأخواتها | لا يصدر شيئاً |

فعّل القالب مرة واحدة في كل نسخة من المستودع:

```
git config commit.template .gitmessage
```

**لا تُنشئ وسماً يدوياً ولا تنقله.** و`CHANGELOG.md` مولّد — لا يُحرَّر.

## صفحة المعاينة

```
npm install
npm run dev
```

ثم افتح `http://localhost:3000`. الصفحة تعرض لوحة الألوان وسلّم الخطوط والمكوّنات بحالاتها،
مع مبدّل الوضع الفاتح والداكن ومبدّل الاتجاه.

## إعادة بناء ملفات السجلّ

```
npm run registry:build
```

يولّد `public/r/*.json` من `registry.json`. أعد البناء بعد أي تعديل على المكوّنات.

---

## بنود مفتوحة

**تنسيق المبالغ في المستندات المطبوعة وملفات PDF.**
`naf-terms.md` و `CLAUDE.md` يقضيان بأن تبقى المطبوعات وملفات PDF على «ر.س» لا على الرمز `U+20C1`، لأنها قد تُفتح ببرامج لا تحمّل خط الرمز فيظهر مربع فارغ.

القاعدة مكتوبة، ولا مولّد مستندات في المستودع ينفّذها بعد. حين يُبنى، القاعدة تنتظره — ولا يُبنى دون الالتزام بها.

---

## القواعد

اقرأ `CLAUDE.md` قبل أي تعديل. أهمها: لا قيمة تصميم مباشرة، والاتجاه من اليمين لليسار هو الأصل،
وكل نص من `naf-terms.md` وكل أيقونة من `naf-icons.md`.
